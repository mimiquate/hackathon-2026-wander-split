# In-city place search via Mapbox Search Box API, scoped to the active city

The design's "buscá un lugar en la ciudad" search is backed by a hardcoded per-city list of a handful of landmarks — fine for the mock's three Iberian cities, useless for a real trip anywhere in the world. We call Mapbox's Search Box API (the POI/category-aware sibling of the Geocoding API [ADR 0006](0006-mapbox-geocoding-city-search.md) already uses for city-level search), biased with a `proximity`/`bbox` around the active city's coordinates so results are landmarks, hotels, and venues in that city rather than anywhere on Earth. This keeps one geocoding vendor and API key for the whole route+city domain instead of adding a second provider, at the cost of a different Mapbox endpoint/response shape to integrate than #8's city search already handles.
