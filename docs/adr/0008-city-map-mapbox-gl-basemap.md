# CityMap renders on real Mapbox GL tiles, not a bare SVG pin-plot

The design's `CityMap` component doesn't render any street/basemap at all — it's a custom `d3-geo`-projected SVG showing only the marked-place pins to real relative scale plus a metric scale bar, deliberately avoiding "invented streets or coastlines." We instead render `CityMap` on Mapbox GL JS with real vector tiles, dropping custom markers for each marked place, since a group planning a trip benefits from seeing actual streets/context around their hotel and landmarks, not just relative dots on a blank canvas. This pairs with the same Mapbox account [ADR 0006](0006-mapbox-geocoding-city-search.md) and [ADR 0007](0007-mapbox-search-box-city-scoped-places.md) already use for search, at the cost of normal map tile loading/attribution and giving up the design's fit-to-pins auto-framing in favor of standard pan/zoom (still initialized fit to the city's marked places).
