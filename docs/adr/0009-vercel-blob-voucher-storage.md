# Vercel Blob for voucher file storage

Bookings need real file uploads (PDF confirmations, screenshots) attached to a voucher, and nothing in the stack so far stores binary files — Postgres via Prisma ([ADR 0004](0004-postgres-prisma-persistence.md)) holds structured rows, not blobs. We pick Vercel Blob over a general-purpose object store like S3: the app already deploys on Vercel with Vercel Postgres provisioned the same way (env vars land in the project automatically, no separate account or IAM setup to manage), and its client-upload flow lets the browser push a file straight to Blob storage using a short-lived token the server hands out, instead of routing every upload through a serverless function's body-size limits. This costs some vendor lock-in and a thinner feature set than raw S3 (no lifecycle rules, a simpler access-control model), the same tradeoff ADR 0004 already accepted for Postgres, for the same reason.
